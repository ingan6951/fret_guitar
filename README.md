# 기타 가이드

일렉 기타 코드 운지법을 보여 주는 웹앱 (Next.js). 코드 폼 데이터는 `lib/chords.js`에 직접 적은 것만 사용합니다.

## 코드 폼 추가하기
`lib/chords.js`의 `CHORDS`에 한 줄을 추가합니다. (맨 앞 8개는 오픈 코드, 그 뒤는 프렛을 올린 바레 폼이고 맨 끝에 C·G·D 모양을 옮긴 폼이 있습니다.) `frets`는 6번 줄 → 1번 줄 순서이고, 숫자는 프렛(0=개방), `null`은 뮤트입니다.

```js
{root:4, q:'min', frets:[0,2,2,0,0,0]} // Em
```
`root`는 0=C … 11=B, `q`는 `maj`·`min`·`7`·`m7`·`maj7`·`sus4`·`sus2`·`add9`·`6`·`m6`·`7sus4`·`mmaj7`·`dim`·`dim7`·`m7b5`·`aug`·`5` (`lib/fretlogic.js`의 `QUALITIES`). 새 코드 종류는 `QUALITIES`에 구성음을 먼저 추가합니다.

## 진행
위쪽에 마디 4개가 먼저 그려져 있고, 마디를 눌러 선택한 뒤 폼 카드 오른쪽 위 `+`로 그 마디에 코드를 넣습니다(넣으면 다음 마디가 선택됩니다). 마디 아래의 `마디 추가`로 8마디까지 늘릴 수 있고, 앞뒤 마디의 폼에서 이동이 적은 순으로 카드가 정렬됩니다. 찬 마디를 누르면 ↺로 바꾸거나 `마디 비우기`를 할 수 있습니다.

진행은 여러 개를 만들 수 있습니다(최대 20개). 진행 이름(최대 30자)을 바로 고쳐 쓰고, 목록에서 다른 진행으로 전환하거나 `새 진행`으로 추가하며, `진행 삭제`는 내용이 있으면 한 번 더 눌러야 지워집니다(마지막 하나를 지우면 빈 진행이 남습니다). 예전에 저장된 진행 하나는 '진행 1'로 옮겨 열립니다.

## 진행 공유
진행 줄의 `링크 복사`로 `?p=...&t=제목` 링크를 만들고, 다른 기기·브라우저에서 그 링크를 열면 같은 진행이 **새 진행으로 추가**되어 불러와집니다(기존 진행은 지워지지 않고, 서버 저장 없음).

## 테스트
