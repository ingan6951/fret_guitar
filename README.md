# 기타 가이드

일렉 기타 반주용 코드 폼 가이드입니다. 근음과 코드를 고르면, 베이스(최저음) 줄에 따라 짚을 수 있는 폼을 지판 위에 보여줍니다. 폼 카드의 +로 코드 진행을 이어 담으면 앞 폼에서 손 이동이 적은 폼부터 보여 줍니다. 연습 중 폰·태블릿에 띄워 놓고 쓰는 것을 전제로 만들었습니다.

**사이트: https://fret-guitar.vercel.app**

## 구성

Next.js(App Router)로 만든 정적 사이트입니다. 서버 없이 `out/`에 HTML·JS로 내보냅니다.

| 경로 | 설명 |
| --- | --- |
| `app/` | 페이지(`page.jsx`), 레이아웃, 전역 스타일(`globals.css`) |
| `components/FretGuide.jsx` | 화면 전체 (상태·조작) |
| `components/Diagram.jsx` | 지판 그림 (SVG) |
| `lib/fretlogic.js` | 폼 생성·손가락 번호·이동 비용 (UI와 무관한 순수 함수) |
| `lib/settings.js` | 기본값, 저장값 검증, 브라우저 저장 |
| `tests/logic.test.js` | 로직 검증 (전수 탐색과 대조) |
| `tests/ui.test.jsx` | 화면 테스트 (jsdom + Testing Library) |
| `scripts/test-ui.mjs` | 화면 테스트 실행기 (esbuild로 묶어 node 테스트 러너로 실행) |

## 기능

- **근음**: 12음 (♯/♭ 표기 전환)
- **코드** (16가지): Major, minor, dim, aug, sus2, sus4, 6, m6, 7, maj7, m7, m7♭5, dim7, 7sus4, m(maj7), add9
- **폼 넘기기**: 좁은 화면(폰)에서는 폼 카드를 가로로 한 장씩 쓸어 넘기고(◀ ▶ 버튼·번호·키보드 좌우 화살표도 가능), 넓은 화면(720px 이상, 태블릿 가로·PC)에서는 격자로 펼쳐 보여줌. 진행 결과도 코드 한 장씩 넘김
- **베이스**: 폼에서 가장 낮은 소리가 나는 줄(최저음의 줄)
- **프렛**: 기본은 "전체". `− 3 +`로 숫자를 올리고 내리면 소리 나는 모든 음이 그 프렛 이상인 폼만 보여줌(개방현 제외, 기본 위치와 한 옥타브 위 위치를 모두 후보로). 진행에도 같이 적용. 폼이 없어지는 숫자로는 + 가 막힘
- **폰 화면**: 조건 여섯 줄을 화면 아래에 고정해 엄지로 닿게 함(넘치면 스크롤)
- **화면 구성**: 근음·코드·하이톤·음 개수·베이스·프렛을 한 열에 나란히 둡니다(폰에서는 화면 아래에 고정). 표시 방식·♯/♭·옥타브는 "⚙ 보기"에 모음.
- **음 개수**: `− 4 +`로 1~6. 구성음 수 이하이면 구성음 중 그 개수만큼 고른 모든 조합, 구성음보다 많으면 모든 구성음을 쓰고 일부를 겹쳐서(옥타브 겹음) 채움. 6음은 베이스가 6번 줄뿐이고 5음은 6·5번 줄 베이스만 가능(손가락 4개와 바레로 잡을 수 없는 폼은 제외)
- **하이톤**: 근음·코드 옆 셀렉트로 가장 높은 줄에서 울리는 음을 구성음 도수(1·3·5·7…)로 지정 (기본 "자동"). 지금 조건에서 그 음이 맨 위인 폼이 없으면 비활성. 
- **줄 배치(붙여서 / 쉘)**: 따로 고르지 않습니다. 코드 화면에서는 붙여서(인접한 줄)와 쉘(음 사이 한 곳에서 한 줄 건너뛰기) 폼이 함께 나오고 쉘 카드에는 "쉘" 표시가 붙습니다. 쉘은 손으로 잡기 어려운 경우를 뺍니다: 베이스 바로 위 줄을 비우는 폼, 4번 줄을 비우는 폼(엄지로 뮤트할 수 없음)은 없고, 손 폭은 프렛 차 3 이하입니다. 예: 3음 → 5·4·2번 줄(3번 줄을 비움). 진행에서는 붙여서만 쓰되, 쉘을 섞어야 폼이 생기거나 총 손 이동이 줄어드는 진행에서만 쉘 폼을 후보에 포함합니다(자동).
- **베이스**: 가장 낮은 소리가 나는 줄. `− 4번 줄 +` 스테퍼로 전체 → 1번 줄 … 6번 줄 사이를 오가며, 폼이 없는 줄은 건너뜀
- **진행 만들기**: 폼 카드 오른쪽 위의 **+** 를 누르면 그 폼으로 진행이 시작됩니다. 다음 코드를 고르면 카드가 **앞 폼에서 손 이동이 적은 순**으로 정렬되고(카드에 "앞 N프렛 이동" 표시), 마음에 드는 폼의 +로 최대 8개까지 이어 담습니다. 담은 폼은 운지(줄마다 프렛)째로 보관하므로 이후 조건을 바꿔도 그대로입니다. 다음 코드를 고르는 동안에는 기준이 되는 **이전 폼**을 카드 목록 위에 작게 보여 줍니다(자리를 다시 고를 때는 이전·다음 폼).
- **진행 고치기**: 진행 칩을 누르면 그 자리가 선택됩니다(코드도 불러옴). 카드의 +가 ↺로 바뀌고 순서는 **앞뒤 폼 모두에서 가까운 순**이며 "지금 이 자리"의 폼이 표시됩니다. ↺로 바꾸거나 코드를 바꿔 다른 코드로 교체할 수 있고, **제거**를 누르면 그 자리만 빠집니다. 이웃 폼은 그대로 두고 칩 사이의 이동 거리(프렛)만 다시 계산되므로, 전체를 다시 정렬할 필요가 없습니다. **진행 보기**는 담은 폼을 차례로 모아 보여 줍니다.
- 표시 방식: 손가락 번호 / 음 이름 / 도수
- 한 옥타브 위로 (최대 17프렛)
- 폼이 없는 조합은 버튼을 비활성화해 빈 화면이 나오지 않게 처리
- 설정은 브라우저에 저장

## 개발

Node.js 20.9 이상이 필요합니다.

```sh
npm install
npm run dev      # http://localhost:3000
npm test         # 로직 + 화면 테스트
npm run build    # out/에 정적 사이트 생성
```

## 배포

Vercel에 연결되어 있어 `main`에 푸시하면 자동으로 배포됩니다: https://fret-guitar.vercel.app

- Vercel은 빌드(`npm run build`)만 하고 테스트는 돌리지 않으므로, 푸시하기 전에 `npm test`를 실행해 주세요.
- 배포 상태는 GitHub 커밋 옆의 Vercel 표시나 Vercel 대시보드에서 볼 수 있습니다.

## 폼 생성 방식

- 근음 프렛은 `(근음 − 개방현 음) mod 12`로 구하고, 오프셋이 음수가 되면 12프렛을 더합니다.
- 켠 구성음의 모든 순서(전위 포함)를 베이스 줄부터 위로 한 줄에 하나씩 놓고(쉘이면 베이스 바로 위와 4번 줄을 뺀 사이 한 곳에서 한 줄을 비움), 가장 낮은 줄의 음을 기준으로 상대 프렛을 계산합니다.
- 손 폭은 3프렛 이내로 계산합니다.
- 손가락 번호는 가능한 배치를 모두 따져 고릅니다(개방 위치는 실제 누르는 프렛 기준, 개방현은 손가락 없음). 규칙: 높은 프렛일수록 높은 번호, 같은 프렛의 두 손가락은 굵은 줄이 낮은 번호, 바레는 사이 줄이 모두 같거나 더 높은 프렛일 때만(치지 않는 줄·개방현은 가로지르지 않음). 그중 손을 덜 벌리고, 1번 손가락부터 쓰고, 바레와 같은 프렛 여러 손가락을 적게 쓰는 배치를 고릅니다.
- 바레는 사이의 줄이 모두 더 높은 프렛을 누를 때만 이어 그리고, 치지 않는 줄·개방현은 가로지르지 않습니다.
- 진행: 담은 폼을 운지(줄마다 프렛)째로 저장해 두고, 다음 코드의 후보 폼은 앞 폼과의 이동 비용(손 위치 차이가 기본, 같으면 베이스 줄·손가락 움직임이 적은 쪽) 순으로 정렬합니다. 자리를 다시 고를 때는 앞뒤 폼과의 비용 합으로 정렬합니다.
