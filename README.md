# fret_guitar

일렉 기타 반주용 **코드 운지 가이드**. 근음과 코드를 고르면, 베이스(최저음) 줄에 따라 짚을 수 있는 폼을 지판 위에 보여줍니다. 연습 중 폰·태블릿에 띄워 놓고 쓰는 것을 전제로 만들었습니다.

## 구성

| 경로 | 설명 |
| --- | --- |
| `fretguide/index.html` | 앱 본체 (단일 HTML, 외부 빌드 없음) |
| `fretguide/test.js` | 폼 생성 로직 검증 (전수 탐색과 대조) |
| `fretguide/ui-smoke.js` | UI 조합 스모크 테스트 |
| `fretguide/ui-disabled.js` | 불가능한 조합의 버튼 비활성화 테스트 |
| `fretguide/harness.js` | UI 테스트용 가짜 DOM |

## 기능

- **근음**: 12음 (♯/♭ 표기 전환)
- **코드**: Major, minor, 7, maj7, m7
- **구성음**: 1·3·5·7도를 켜고 끄기. 켠 구성음을 한 줄에 하나씩, 인접한 줄에 놓은 폼만 나옴 (근음을 꺼서 루트리스 보이싱도 가능, 트라이어드에서는 7도 비활성)
- **베이스**: 가장 낮은 소리가 나는 줄 (1~6번 줄), 전체
- **프렛 범위**: 결과에서 가능한 5프렛 구간만 칩으로 표시
- 표시 방식: 손가락 번호 / 음 이름 / 도수
- 한 옥타브 위로 (최대 17프렛)
- 폼이 없는 조합은 버튼을 비활성화해 빈 화면이 나오지 않게 처리
- 설정은 브라우저에 저장

## 사용법

`fretguide/index.html`을 브라우저에서 열면 됩니다.

## 테스트

Node.js가 필요합니다.

```sh
cd fretguide
node test.js
node ui-smoke.js
node ui-disabled.js
```

`ui-*.js`는 `harness.js`를 함께 사용합니다.

## 폼 생성 방식

- 근음 프렛은 `(근음 − 개방현 음) mod 12`로 구하고, 오프셋이 음수가 되면 12프렛을 더합니다.
- 켠 구성음의 모든 순서(전위 포함)를 베이스 줄부터 위로 한 줄에 하나씩 놓고, 가장 낮은 줄의 음을 기준으로 상대 프렛을 계산합니다.
- 손 폭은 3프렛 이내, 한 프렛에 손가락 하나로 계산합니다.
